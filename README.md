# Análise de Dados de Recursos Humanos — TechNova Solutions

## Sobre o Projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados de Recursos Humanos (RH) de uma empresa fictícia chamada **TechNova Solutions**, utilizando Python para transformar dados em informações relevantes para a tomada de decisões.

A análise busca identificar padrões relacionados ao perfil dos colaboradores, remuneração, satisfação profissional, absenteísmo e rotatividade de funcionários (*turnover*).

## Objetivos

- Analisar a distribuição dos funcionários por departamento.
- Calcular e comparar a média salarial entre departamentos.
- Investigar a rotatividade de funcionários.
- Avaliar os níveis de satisfação profissional.
- Analisar o absenteísmo dos colaboradores.
- Identificar possíveis padrões relacionados aos desligamentos.
- Apresentar informações que possam auxiliar o planejamento estratégico do RH.

## Tecnologias Utilizadas

- **Python:** linguagem de programação utilizada na análise.
- **Pandas:** manipulação, organização e tratamento dos dados.
- **Matplotlib:** criação de gráficos e visualizações.
- **Seaborn:** visualização estatística dos dados.
- **Jupyter Notebook:** desenvolvimento e documentação das análises.
- **Git e GitHub:** versionamento e compartilhamento do projeto.

## Análises Desenvolvidas

### 1. Perfil dos Colaboradores

Análise da distribuição de funcionários por departamento, idade e cargo.

### 2. Análise Salarial

Comparação das médias salariais entre os departamentos da empresa.

### 3. Rotatividade de Funcionários

Investigação dos desligamentos e cálculo da taxa de rotatividade, conforme os dados disponíveis.

### 4. Satisfação Profissional

Análise das notas de satisfação dos colaboradores e comparação entre funcionários ativos e desligados.

### 5. Absenteísmo

Avaliação da quantidade de faltas dos funcionários, buscando identificar padrões que mereçam atenção do setor de RH.

## Resultados Esperados

A partir das análises, espera-se identificar padrões que contribuam para:

- Melhor compreensão do perfil dos colaboradores.
- Acompanhamento dos indicadores de Recursos Humanos.
- Identificação de departamentos com maior rotatividade.
- Avaliação das diferenças salariais entre áreas.
- Desenvolvimento de estratégias de retenção de talentos.
- Apoio à tomada de decisões baseada em dados.

Os resultados e as conclusões definitivas serão apresentados após a execução das análises sobre a base de dados.

## Sobre a Empresa

A TechNova Solutions é uma empresa fictícia do setor de tecnologia, criada exclusivamente para fins educacionais e para a prática de análise de dados.

Todos os dados utilizados no projeto são fictícios e não representam funcionários reais.
